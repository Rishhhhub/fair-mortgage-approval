# Fair Mortgage Approval Decisions

Advanced Data Science (ADS) end-term project, Group 8.
Stakeholder: the credit-risk team of a US home-loan lender.
Question: what drives mortgage denials, are there unfair gaps between groups, and can we build a fair, explainable approval model?

## Status
Stage 1 (problem definition and data audit) and data acquisition in progress.

## Data (all public, no Kaggle)
| Source | What | Link |
|---|---|---|
| HMDA (CFPB/FFIEC) | mortgage applications 2018-2023 | https://ffiec.cfpb.gov/data-browser/ |
| Census ACS 5-year | tract income, house value, poverty, unemployment | https://api.census.gov/ |
| FRED | 30-year mortgage rate | https://fred.stlouisfed.org/series/MORTGAGE30US |

HMDA sample: first-lien, owner-occupied home-purchase loans that were originated or denied; a fixed 5% random sample per state-year (seed 42 + year). Every download is logged in data/raw/hmda/sampling_log.csv (not committed; regenerated by the script).

## Reproduce
    pip install -r requirements.txt
    python src/01_download.py hmda --years 2018-2023 --states all
    python src/01_download.py fred
    python src/01_download.py acs --years 2018-2023

Raw data is not committed (size); the scripts rebuild it.

Only methods from the ADS course handout. Spark is not used (instructor advised avoiding it unless required).
